Texto

En este texto destacamos una palabra con énfasis (em) y otra con importancia visual (strong). También podemos añadir aclaraciones de letra pequeña (small) o texto tachado que ya no es válido (s).

Como dice en el libro El Quijote: De grandes cenas están las sepulturas llenas. Aquí definimos un término: Semántica web, y añadimos una sigla explicada: HTML.

La práctica se entregará el 15 de octubre de 2026. Para clonar un repositorio usamos el comando git clone, donde url representa la dirección del proyecto.

Si el sistema falla mostrará el mensaje Error 404: Not Found. Para guardar los cambios en el editor pulsa la combinación Ctrl + S.

Fórmulas y expresiones químicas: agua H2O con subíndice (sub), y potencia 28 = 256 con superíndice (sup).

Formato tipográfico clásico: término en otro idioma hardware (i), texto en negrita sin énfasis extra (b) y texto subrayado (u).

Texto resaltado con fluorescente (mark) y un fragmento con estilo en línea dentro de un span.
